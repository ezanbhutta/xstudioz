# Prototypes

Design spikes. Not part of the site.

Nothing in here is registered in `site/site.config.ts`, so the manifest build
ignores it: it is never compiled into `dist/`, never linked, never in the
sitemap. Open a file directly in a browser to view it.

## lighting-rig

The spike behind the dark direction. Establishes one law: the brand gradient is
never painted on anything, it is cast.

Two light sources sit exactly 180 degrees apart through the centre, because that
is the mark's measured symmetry (the counter matches itself under rotation at
22 of 22 sampled points; 90 degrees fits only 19 of 30, and there is no mirror
symmetry). Light is thrown in hard-edged wedges on the mark's 45 degree
diagonals rather than soft blooms, so it slices type instead of blurring behind
it. The mark is not drawn: it stands in the beam and throws its shadow.

Body copy is deliberately never lit, so readability never depends on where the
lamps happen to be pointing.
